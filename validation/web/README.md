# 控制台离线浏览器回归

用 Chromium 打开 `web/dist`，以固定数据替代全部 API，验证列表、跳转及错误状态。
不连接真实后端、不调用模型、不下发主机指令，也不验证实际情报源或生产部署。
脚本只监听本机临时端口，结束后关闭；未知 API、未定义的写操作、外部资源请求和未捕获的页面异常均使测试失败。

## 运行

在仓库根目录执行。首次安装 Python 依赖与 Chromium 需要网络；测试过程本身使用本地数据。

```bash
npm --prefix web ci
npm --prefix web run build
python3 -m venv /tmp/openxdr-web-venv
/tmp/openxdr-web-venv/bin/pip install -r validation/web/requirements.txt
/tmp/openxdr-web-venv/bin/python -m playwright install chromium
/tmp/openxdr-web-venv/bin/python validation/web/smoke.py
```

运行环境需具备 Chromium 的系统依赖。脚本不负责安装系统软件。
默认读取仓库的 `web/dist`，可用 `--dist /path/to/dist` 指定其他构建目录。
不要用它代替 `npm --prefix web run lint`、后端集成测试或部署后的实际业务验收。

## 覆盖范围

每个场景分别以 1440 和 390 像素宽度运行，使用独立浏览器上下文；默认中文，页面恢复场景同时验证英文：

- 资产标签：卡片跳转、URL 同步、刷新、前进后退和无效标签回退。
- 资产分页：超过一页的数据、记录减少与重新增加、切换主机时重置页码、固定每页条数。
- 资产查询失败：已有零值缓存时显示未知计数，事件、待办与原始事件列表重试后恢复计数。
- 事件与待办列表：超过 500 条待办、越界页码回退、数据减少时保留筛选条件、浏览器历史切页清空旧勾选。
- 总览：待办、资产、审批查询失败时显示未知计数，不误报“全部处理完毕”；恢复后重新计数；失败时不沿用缓存零值。
- AI 对话关联对象：事件或待办读取失败后重试、按引用 ID 找到默认前 500 条以外的待办并打开对应列表。
- 待办操作栏：长标题与长主机名下文字不拆行、控件不重叠，横向滚动后可打开处置弹窗与关联会话，整页不横向溢出。
- 页面恢复：渲染异常显示友好提示并保留导航，可重新加载或回首页；页面脚本返回 404 或被 SPA 回退替换为 HTML 时显示恢复入口，资源恢复后可重新加载。
- 情报密钥设置：以固定假密钥验证保存、留空不覆盖、显式清空与恢复环境默认值；响应仅含配置状态与尾部提示。
- 情报订阅异常：读取失败时禁止同步、手工情报仍可查看；重试恢复、明确提交空数组关闭订阅、保存成功但同步失败后重新读取实际开关；未成功同步时不把尝试时间显示成成功时间。

默认输出目录为系统临时目录下的 `openxdr-web-smoke`，可通过 `--output` 修改。
每组结果打印为 JSON，汇总写入 `results.json`；失败场景保存截图。默认十个场景各测两种宽度，全部二十组通过才返回 0。
可用 `--scenario overview_errors` 等参数只运行指定场景的两个宽度；多次传入可选择多组，退出码仍要求所选场景全部通过。
默认使用浅色主题；`--theme dark --output /tmp/openxdr-web-smoke-dark` 可单独验证深色主题，结果中记录实际选择。
固定数据仅验证前端行为和请求参数，不能证明真实 API、RBAC、数据库分页或采集链路正确。

增加页面依赖的接口时，应在 `Fixtures.payload` 中补齐有意义的响应结构，不能用“所有未知接口都返回空数组”掩盖遗漏。
